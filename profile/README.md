## Active projects

### [Rastahunden](https://rastahunden.com)
**Sveriges hundvänliga karta.** Sole-source national directory of dog-friendly places — hundrastgårdar, koppelfria zoner, hundbad, hundvänliga caféer. 596+ verified locations across 116 cities. Free for users. Stack: Next.js 16 · Supabase · Mapbox · Netlify · Resend.

### [godot-space-shooter](https://github.com/orangeelefant/godot-space-shooter)
Godot-based 2D space shooter with crash-logging autoload and an in-game debug overlay. Personal sandbox for Godot ecosystem.

### [space-shooter / Stjärnkrigaren](https://github.com/orangeelefant/space-shooter)
Phaser 3 + TypeScript port of the same game. Originally a Phaser experiment.
